# react-native-floating-sheet

A floating bottom-sheet navigation component with expandable tab screens for React Native.

## Installation


```sh
npm install react-native-floating-sheet
```


## Usage


```js
import { multiply } from 'react-native-floating-sheet';

// ...

const result = multiply(3, 7);
```
